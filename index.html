JIL Taguig Presenter Instructions

1. Choose the root folder

Select the local media folder first. Downloaded cloud files and exported PDFs are saved there.

2. Add media

Use the single Choose Files control in Media Assets for images, videos, PDFs, audio, and PPTX. A PPTX automatically opens the PowerPoint preparation and editing workflow.

3. Reuse cloud PPTX files

Open File Transfer → View cloud files, then enable the PPTX filter. Choose Add to Scene to reuse a PowerPoint already stored in Google Drive. It does not upload the file again.

4. Preview and Go Live

Click an asset or presentation slide to queue it in Preview. Confirm it, then click Go Live to send it to Live View and the Display Screen.

5. Navigate presentations

Use the previous and next controls in Live View to change the live slide immediately. Clicking thumbnails changes Preview only until Go Live is pressed.

6. Edit PowerPoint

Select the pencil icon below Preview. Choose a text box and change the font size. Changes save automatically. Use the PDF icon only when a PDF copy is needed.

7. Display screen

Detect the intended monitor, open the Display Screen, and use Background or Fade to Black only when needed.

8. File Transfer

View cloud files shows cloud storage and includes a PPTX-only filter. View Root Files shows local media. Add to Scene reuses an existing file whenever possible.
